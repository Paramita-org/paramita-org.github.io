«Practiquemos juntos» — dos direcciones

El problema: hoy este bloque y la banda del boletín comparten el mismo fondo azul y la misma composición (eyebrow + Fraunces con em dorado, centrado), así que se leen como el mismo cierre repetido. La idea acordada: el azul de cierre es del boletín; este bloque baja de intensidad y deja de ser una banda azul gemela.

Debajo de cada variante verás el mock de la banda azul del boletín tal cual está ahora, para comprobar que el relevo ya no compite.

Un solo CTA, nivel secundario → el globo. En vez de dos botones, un único CTA de apoyo abre la Guía del sendero (el globo con las preguntas). Secundario y no primario a propósito: el «volumen máximo» se reserva al boletín de abajo, y la acción primaria real del catálogo son las tarjetas de curso. Pruébalo: al pulsar «Encontrar mi curso» se abre el mock del globo abajo a la derecha. El label es provisional (de Ale).
